# Dicionário de Dados do CAF

Aplicação de consulta baseada na etapa 1 da aplicação de compartilhamento de dados de `caf-cod/formulario`.

- Pessoa Física (PF): 60 variáveis.
- Pessoa Jurídica (PJ): 35 variáveis.
- Busca por variável, descrição ou valor, sem distinção de acentos.
- Navegação por seções e expansão de valores possíveis.
- Classificações de apoio preservadas da aplicação original.

A aplicação contém somente o dicionário em modo de leitura. Não coleta dados, não seleciona variáveis, não gera termos e não envia e-mails.

## Executar

Abra `index.html` em um navegador. O arquivo é independente e não requer instalação de dependências ou compilação.

## Origem

Dicionários e classificações extraídos de `caf-cod/formulario`, versão `311440a3469297b18bebc11fc012d8772e07b852`.
